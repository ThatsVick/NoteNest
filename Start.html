Was ist NoteNest

Es soll einfach gesagt Daten verwalten, Notizen aus dem Unterricht speichern, die man später ansehen, bearbeiten und zum Üben benutzen kann. Ich mache gerade eine Umschulung zum Fachinformatiker für Anwendungsentwicklung und NoteNest ist ein kleines Projekt, woran ich bastle, um erste Erfahrung im Bereich Programmieren mit HTML, CSS und JavaScript zu sammeln.
